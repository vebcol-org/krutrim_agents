# Agent Memory

Durable notes for the research agent, loaded into every run. Keep this file short — it costs context on every single turn. Add only things that should apply to *every* future report, not facts about one specific topic or one specific conversation.

## Standing Preferences

- Default to the `report-writing` skill's structure for anything the user calls "a report."
- No standing preferences recorded yet — this file is intended to be edited by the operator (not the agent; write access is denied by policy), as usage reveals durable preferences worth keeping.
