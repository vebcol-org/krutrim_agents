# Agent Memory

Durable notes for the sales outreach agent, loaded into every run. Keep this file short — it costs context on every single turn. Add only things that should apply to *every* future draft, not facts about one specific prospect or one specific conversation.

## Standing Preferences

- Default to the `outreach-drafting` skill's approach for anything the user calls a "draft" or "outreach note."
- No standing preferences recorded yet — this file is intended to be edited by the operator (not the agent; write access is denied by policy), as usage reveals durable preferences worth keeping.
