# Agent Memory

Durable notes for the trading research agent, loaded into every run. Keep this file short — it costs context on every single turn. Add only things that should apply to *every* future analysis, not facts about one specific ticker or one specific conversation.

## Standing Preferences

- Default to the `trading-analysis` skill's report structure for anything the user calls "an analysis."
- No standing preferences recorded yet — this file is intended to be edited by the operator (not the agent; write access is denied by policy), as usage reveals durable preferences worth keeping.
