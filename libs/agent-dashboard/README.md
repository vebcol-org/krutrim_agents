# agent-dashboard

This library was generated with [Nx](https://nx.dev).

Published as `@krutrim_agent/agent-dashboard` — a standalone rendering library for the `AgentDashboardWorkbook` JSON contract (all 16 chart types via Apache ECharts + lightweight-charts, theming, page layout, filters, lazy/chunked data loading). Not wired into `apps/web` or `libs/agent-renderers` yet — see [`docs/agent-dashboard/README.md`](../../docs/agent-dashboard/README.md) for the full docs.

## Running unit tests

Run `pnpm exec nx run agent-dashboard:test` to execute the unit tests via [Vitest](https://vitest.dev).
